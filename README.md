# Tableau Data Wrangling & Analytics Project

## Overview

This project focuses on cleaning, transforming, and analyzing a large dataset containing 500,000+ records using Python and Pandas. The processed data was then used to develop interactive visualizations and dashboards in Tableau to identify trends, patterns, and insights within the dataset.

The project demonstrates an end-to-end data analytics workflow, from raw data preprocessing and wrangling to visualization and communication of analytical findings.

## Objectives

- Clean and preprocess a large-scale dataset
- Handle missing and inconsistent data
- Transform data into a suitable format for analysis
- Perform exploratory data analysis
- Identify meaningful trends and patterns
- Create interactive Tableau visualizations and dashboards
- Communicate analytical findings through data visualization

## Technologies & Tools

- **Python**
- **Pandas**

- **Jupyter Notebook**

## Project Workflow

### 1. Data Preparation

The raw dataset was inspected to understand its structure, data types, missing values, and potential inconsistencies.

### 2. Data Wrangling

Python and Pandas were used to:

- Clean and transform the dataset
- Handle missing values
- Correct data types
- Remove or manage inconsistent records
- Prepare variables for analysis

### 3. Exploratory Data Analysis

The cleaned dataset was analyzed to identify:

- Distribution of key variables
- Relationships between variables
- Trends and patterns
- Potential outliers and anomalies

### 4. Data Visualization

The processed data was imported into Tableau to create interactive charts and dashboards.

The visualizations were designed to make trends and relationships easier to understand and communicate.

## Dataset

The project uses a dataset containing **500,000+ records**.
